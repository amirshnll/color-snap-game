# Color Snap

## Short description

Name the ink color, not the written word.

## Description

Color Snap is a lightweight, multilingual browser-extension game inspired by the Stroop effect. Players identify the displayed ink color while ignoring the meaning of the color word, with accessible visual options, sound controls, and locally saved records.

## Purpose

The extension provides a quick focus and cognitive-control exercise that can be played directly from the browser toolbar without opening a separate website.
